# ELECTRONIC GAME BALL (1980)

1980年に登場した名作携帯液晶ゲームをリスペクトし、Web技術（HTML5 Canvas + 純粋なJavaScript/CSS）だけで再現したブラウザゲームです。
画像や外部ライブラリを一切使用せず、単一のHTMLファイル（`index.html`）のみで動作します。

## プレイURL
👉 **[https://nande-dayo.github.io/gw-ball/](https://nande-dayo.github.io/gw-ball/)**

## 操作方法

### PC
- `[←]` キー：左ポジションに構える
- `[→]` キー：右ポジションに構える

### スマートフォン / タブレット
- 画面下の赤いボタン（左 / 右）をタップして操作します。

## ルール
- 落ちてくるボールをお手玉のようにキャッチして投げ返します。
- キャッチに成功するごとに得点が入ります。
- 30点を超えるとボールが2球に増え、徐々にスピードアップします。
- ボールを落とすとゲームオーバーです。

## 技術仕様
- 完全スタンドアロン（依存ライブラリなし、外部画像なし）
- 実時間基準（300ms）の滑り込み猶予判定
- 2球同時落下回避アルゴリズム（11歩大アーチ / 9歩中アーチの軌道動的選択）
